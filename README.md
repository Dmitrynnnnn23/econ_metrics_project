# README.md

## Парсер мастеров с Profi.ru

Скрипт собирает данные о мастерах с сайта Profi.ru и сохраняет их в CSV.

---

## Что умеет

* открывает страницу с мастерами
* собирает профили
* сохраняет данные в файл
* делает удобную таблицу через `pandas`

---

## Установка

```bash id="5nkg8f"
pip install -r requirements.txt
```

или:

```bash id="kr86rm"
pip install pandas beautifulsoup4 undetected-chromedriver
```

---

## Запуск

```bash id="xxa53i"
python parser.py
```

---

## Как пользоваться

1. После запуска откроется браузер
2. Пролистайте страницу вниз
3. Нажмите `ENTER` в консоли
4. Дождитесь завершения

---

## Результат

Будет создан файл:

```bash id="1v2sp0"
profi_raw.csv
```

В нем будут данные мастеров:

* имя
* ссылка
* рейтинг
* отзывы
* цены
* опыт
* и другие поля

---

## Если не работает

### Chrome не запускается

Проверьте версию браузера Google Chrome.

### Нет данных

Прокрутите страницу ниже — профили загружаются при скролле.
